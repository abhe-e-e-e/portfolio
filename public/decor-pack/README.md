# Decor Pack website & Bottle Studio

The current documentation is in the [repository README](../README.md), including launch instructions, site previews, the source map, asset/catalogue maintenance and verification steps.

From the repository root, run:

```sh
python3 -m http.server 8080 --bind 127.0.0.1
```

Open http://127.0.0.1:8080/decor-pack/ . No installation or build step is required. Stop the server with Ctrl+C.
